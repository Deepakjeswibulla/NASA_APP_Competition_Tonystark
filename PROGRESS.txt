IMPORTANT DECISIONS (must be preserved by future instances)
--------------------------------------------------------------------------------
D1  The curated dataset is the single source of truth. No artifact fact may be
    written into a React component; add it to scripts/build-data.py and rebuild.
D2  Data is authored in scripts/build-data.py, not edited directly in
    src/data/*.json (the JSON is generated). Re-run the script after any edit.
D3  RESEARCH_SOURCES.txt and DATA_AUDIT.txt are generated by
    scripts/build-docs.py from the dataset. Do not hand-edit them.
D4  The map is schematic and says so. Do not add fabricated geography or
    decorative "terrain" to make it look photographic.
D5  Coordinates are never invented. If a source does not publish one, the record
    stores null or falls back to a site-level coordinate with a map_note.
D6  Source disagreements are recorded, not resolved silently (Pathfinder,
    Viking 1, Apollo 17 odometer, Surveyor 3 visit distance, Spirit recovery
    end date).
D7  No live API at runtime. Imagery is bundled so the demo works offline.
D8  Single-file build (vite-plugin-singlefile) so judges can open the product by
    double-clicking one HTML file.
D9  Plain CSS with tokens instead of Tailwind: fewer moving parts, no build
    plugin, same visual control.
D10 Verification badges are meaningful: 2 records are deliberately marked
    "partially verified" rather than rounded up to "verified".
