# SPACE RELICS — The Machines That Stayed Behind

An interactive, source-backed archive of the hardware left on the Moon and Mars,
built for the **NASA International Space Apps Challenge 2026** (challenge:
*Abandoned but not Forgotten — Storytelling about NASA's Discarded Equipment on
the Moon and Mars*).

Thirteen artifacts, each told as a story: what it was built to do, how it got
there, what it did, what it discovered, how it ended, and where it is now — with
its sources and verification status attached to the record.

---

## Run it

**Option 1 — just open it (no tools needed)**

```
open dist/index.html          # macOS
xdg-open dist/index.html      # Linux
start dist\index.html         # Windows
```

The build is a single self-contained HTML file: JavaScript, CSS and all imagery
are inlined, so it works offline with no server.

**Option 2 — development**

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # writes dist/index.html (single file)
npm run preview    # serve the build
npm run validate   # validate the dataset, writes research/DATA_VALIDATION_REPORT.txt
```

Node 20+ is required for the development commands only.

## The dataset

13 artifacts · 7 Moon · 6 Mars · 11 missions · 8 science themes · 28 sources ·
14 NASA images · 52 timeline events.

```
src/data/artifacts.json    the records (generated)
src/data/sources.json      bibliography with read level and supported claims
src/data/missions.json     mission metadata
src/data/themes.json       science legacy themes
src/data/{planets,categories,statuses,meta}.json
```

### Data policy

- **One source of truth.** Every screen reads from `src/utils/data.js`, which
  reads `src/data/*.json`. No artifact fact is written inside a component.
- **Authored, not hand-edited.** The JSON is generated by
  `scripts/build-data.py`. Edit the script, re-run it, re-validate.
- **Nothing invented.** Coordinates, dates and distances come from published
  sources. Unknown values are `null`, and the gap is written into
  `verification.notes`.
- **Disagreements are kept.** Where sources conflict (Mars Pathfinder
  coordinates, Viking 1 coordinates, Apollo 17 rover distance, Spirit's recovery
  end date) both values are recorded and the record says so.
- **Status is not binary.** `left_on_surface`, `still_partly_operational` and
  `partially_retrieved` are separate states; verification is
  `verified` / `partially verified` / `unverified`.

### Validation

```bash
npm run validate
```

Checks unique ids, required fields, foreign keys, coordinate ranges and accuracy
values, media file existence and metadata, date formats, timeline ordering and
verification consistency. Exits non-zero on error. Current result: **PASS — 0
errors, 0 warnings**.

## Honest limitations

1. **The map is a schematic equirectangular plot**, not a photographic basemap.
   No offline lunar/Martian basemap is available in this environment. The
   graticule, coordinates and labels are real; the shading is not, and the
   interface says so.
2. **Four markers are site-level** (Sojourner, Spirit, Opportunity, the Apollo 16
   UV camera) because no published coordinate exists for the artifact itself.
3. **Sources were read as excerpts**, not end-to-end; each entry records this.
4. **The dataset is curated and finite** — 13 records, not a census.
5. **No live NASA API is used at runtime.** Imagery is bundled from the NASA
   Image and Video Library so the demo cannot break on a bad network.
